# 異界大陸戦記（プロトタイプ）

リアルタイム（一時停止可）の異世界グランドストラテジー。転生した君主が、前世の知識と召喚した異世界人の力で国を作り変える。ブラウザだけで動く（ビルド不要）。
`index.html` を開くか、GitHub Pages で `/isekai-strategy/` を開く。

## 遊び方
- 転生先の国（14か国・6種族）とチートスキルを選んで開始
- **左クリック**：州・軍を選択　**右クリック**：選択中の軍を移動（スマホは「移動」ボタン→タップ）
- ドラッグで地図移動、ホイール／ピンチでズーム、Space で一時停止、1〜5 で速度
- 王国暦1000年〜1100年の100年間。終了時の総開発度で順位が決まる

## 実装済みシステム
| 分野 | 内容 |
|---|---|
| 大陸 | シード値から毎回自動生成（陸約260州＋島、海域約100、地形7種、交易品10種） |
| 内政 | 「政務」（開拓・任命・外交に使う単一の行政力）、州の発展度、建物4種、入植（海を越えた島にも可）、安定度、金貨による投資 |
| 前世の知識 | 18種の発明ツリー（輪作農法、マヨネーズ、活版印刷、羅針盤、火薬、蒸気機関、鉄道、魔導工学など）。転生者の国は知識が貯まりやすい |
| 代官 | 異世界人や現地の人材を州に派遣。州が自然に発展し、人物ごとの特殊効果（農業チート＝税+60%、建築士＝要塞+1など）が付く |
| 商会 | 州に商会を設立。近くの自国商会と連携するほど稼ぎ、他国の商会とは競合。友好国にも出店でき、開戦時は接収される |
| 宗教 | 6宗教。異教徒の州は収入-25%・不穏+3、宣教師で改宗 |
| 反乱 | 州の不穏度（未統合・異教・財政赤字・安定度）に応じて反乱軍が蜂起 |
| 軍事 | 歩兵・騎兵・魔導兵、会戦（ダイス＋地形＋将軍＋士気）、退却、包囲・占領、補充 |
| 将軍 | 攻撃・防御・機動・包囲の4能力。軍事点で任命、軍に配属 |
| 海軍 | 戦列艦・輸送艦、海戦、海上封鎖（包囲速度+25%）、輸送艦の数だけ連隊が渡海できる |
| 外交 | 関係値、同盟、宣戦布告、戦勝点、講和（割譲／属国化／白紙和平）、休戦、属国の貢納金と外交併合 |
| 警戒度・対抗同盟 | 領土を奪うと近隣・同種族ほど警戒度が上がり、50以上の国々が大同盟を組んで一斉に宣戦。講和画面で上昇量を事前に確認できる |
| 時代 | 20年ごとに時代が進み、種族特性（長所・短所）が強まる。魔力収入も時代とともに増える |
| 転生者 | レベルと経験値、スキルツリー（内政・外交・武勇・魔導 各4段） |
| 召喚魔法 | 魔力を使い異世界（日本）からチート能力者を召喚。N/R/SR/SSRのレア度、将軍型5種・顧問型10種。召喚するほど「次元の歪み」が溜まり、魔物の増加・召喚事故・次元の裂け目（強大な魔獣）を招く |
| ダンジョン | 各地に出現。軍を送り込んで攻略すると金貨・魔力・経験値・秘宝（9種）が手に入る |
| 勝利条件 | 魔王討伐（魔王国なら魔界統一）、大陸の覇者（開発度50%）、百年の繁栄 |
| 異世界要素 | 6種族の特性、チートスキル6種、魔物の群れ、魔王軍の侵攻、イベント15種 |
| AI | 徴兵・建設・技術・入植・改宗・商人・造船・将軍・召喚・同盟・属国化・併合・宣戦・進軍・講和 |
| 演出 | 戦闘・陥落・召喚・レベルアップ時のポップアップ文字、波紋、画面振動、フラッシュ、効果音（WebAudio合成、ミュート可） |
| 固有特性 | 14か国それぞれに固有の特性（皇帝の威光、騎士道、商業特権、聖戦、自治都市、世界樹の守り手、精霊契約、鉄壁、名工の血、大移動、魔獣狩り、魔物の王、境界の砦、竜の巣） |
| 国家目標 | 国ごとに3つの目標。達成すると即時報酬か永続ボーナス。AIも達成を目指す |
| 大建造物 | 空中庭園・大魔導塔・叡智の大図書館・天空灯台・黄金の大市場・竜骨の大闘技場・聖光大聖堂・次元門・世界樹の聖域。世界に一つずつで建設競争、征服すれば効果ごと奪える |
| AIの詳細設定 | 開始時に攻撃性・入植・同盟・召喚・大建造物・経済力・知識収入・警戒されやすさ・魔物・反乱・猶予期間を個別に調整（難易度プリセットあり） |
| 古地図 | 羊皮紙に国境沿いを濃く塗る手彩色風の地図。海岸の波紋線・方位線・手描きの地形記号・城と町の印・目盛り付きの枠・羅針盤・表題（年代と主要国の凡例入り）・海の竜。「🗺 保存」で現在の勢力図を画像として書き出せる |
| UI | 羊皮紙と真鍮の古文書風デザイン。時代が進むと差し色が変わる（魔導期は紫の光、終末期は暗い紅） |
| 遊びやすさ | 選択式チュートリアル（実際のゲームの中で6つの目標をこなす）、難易度3段階、滅亡時の再転生、押せないボタンに理由を表示 |
| その他 | セーブ／ロード（localStorage、毎年自動セーブ）、地図モード8種、スマホ対応 |

## ファイル構成
- `js/data.js` 定数・種族・チート・地形などのデータ
- `js/mapgen.js` 大陸と国家の生成
- `js/sim.js` 経済・軍・戦闘・包囲・戦争・講和
- `js/ai.js` AI
- `js/events.js` イベント、ゲーム開始、セーブ
- `js/render.js` 地図の描画・演出
- `js/sound.js` 効果音
- `js/tutorial.js` チュートリアル
- `js/ui.js` UI・入力・メインループ
