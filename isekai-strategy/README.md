# 異界大陸戦記（プロトタイプ）

EU4 風のリアルタイム（一時停止可）異世界グランドストラテジー。ブラウザだけで動く（ビルド不要）。
`index.html` を開くか、GitHub Pages で `/isekai-strategy/` を開く。

## 遊び方
- 転生先の国（14か国・6種族）とチートスキルを選んで開始
- **左クリック**：州・軍を選択　**右クリック**：選択中の軍を移動（スマホは「移動」ボタン→タップ）
- ドラッグで地図移動、ホイール／ピンチでズーム、Space で一時停止、1〜5 で速度
- 王国暦1000年〜1100年の100年間。終了時の総開発度で順位が決まる

## 実装済みシステム
| 分野 | 内容 |
|---|---|
| 大陸 | シード値から毎回自動生成（約240州、地形7種、交易品10種） |
| 内政 | 統治／外交／軍事の3種の君主点、州の開発（税・生産・兵力）、建物4種、技術3系統、入植 |
| 軍事 | 歩兵・騎兵・魔導兵、移動・会戦（ダイス＋地形＋士気）、退却、包囲・占領、補充、維持限界 |
| 外交 | 関係値、同盟（防衛参戦・参戦要請）、宣戦布告、戦勝点、講和（州の割譲／白紙和平）、休戦 |
| 異世界要素 | 6種族の特性、転生者のチートスキル6種、魔物の群れ（スタンピード）、イベント11種 |
| AI | 徴兵・建設・技術・入植・同盟・宣戦・軍の進軍と包囲・講和 |
| その他 | セーブ／ロード（localStorage、毎年自動セーブ）、地図モード5種、スマホ対応 |

## ファイル構成
- `js/data.js` 定数・種族・チート・地形などのデータ
- `js/mapgen.js` 大陸と国家の生成
- `js/sim.js` 経済・軍・戦闘・包囲・戦争・講和
- `js/ai.js` AI
- `js/events.js` イベント、ゲーム開始、セーブ
- `js/render.js` 地図の描画
- `js/ui.js` UI・入力・メインループ
