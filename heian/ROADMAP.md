# 550万分の1 ― 構想メモ

このゲームの目的は「成功すること」ではなく「生きること」。考証にもとづいたうえで、理不尽な死や不運も多くてよい。
目標達成やご褒美でプレイヤーを成功へ導く仕組み（「願い」など）は入れない。

## 構想：家を継いで生き続ける（世代をまたぐモード）

本人が死んだあと、跡取りの子として続きを生きられるようにする。

- 死後の過去帳に「跡取りの◯◯として生きる」を出す。財・家の暮らし向き・縁・氏や通字を引き継ぐ。
- 親の世代の記録（過去帳）は「家の綴り」として一続きに残る。
- 跡取りが決まっていない・子が全員先立っている場合は、家はそこで絶える。
- 通字や氏が受け継がれ、名前の上でも家の連続が見える。

### さらに先：縄文から現代まで

時代ごとに「その時代に生まれたら」を作り、家を継いでいくと時代をまたいで続けられるようにする。

| 時代 | 生まれの母数の例 | 主な要素の候補 |
|---|---|---|
| 縄文 | 人口推計（鬼頭宏など） | 狩猟採集、集落、土器、気候の寒冷化 |
| 弥生・古墳 | | 稲作の伝来、ムラとクニ、渡来人 |
| 奈良 | | 律令、班田、防人、天平の疫病 |
| 平安（このゲーム） | 約550万〜680万人 | 本作 |
| 鎌倉・室町 | | 御家人、惣村、一揆、飢饉 |
| 戦国・江戸 | | 戦乱、検地、身分の固定、飢饉と一揆 |
| 明治以降 | 国勢調査 | 徴兵、工場、戦争、高度成長 |

- どの時代も、史料と研究による考証と、典拠の表示を必須にする。
- 時代の境目（例：1185年→鎌倉）は、生きている途中で「時代が変わったが、暮らしは特に変わらない」と見せる今の作り方を引き継ぐ。
- エンジンは時代ごとの「身分・暮らし向き・出来事・史実・名付け・家族」のデータを差し替えられる形にする。
